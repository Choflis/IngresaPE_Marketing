# Uso de Open Design

Fuentes leídas y aplicadas el 2026-10-28:

- https://github.com/nexu-io/open-design/blob/main/skills/frontend-design/SKILL.md
- https://github.com/nexu-io/open-design/blob/main/design-templates/dashboard/SKILL.md
- https://github.com/nexu-io/open-design/blob/main/design-systems/linear-app/DESIGN.md

Se aplican contrato DESIGN.md, paleta semántica, layout operativo de sidebar/topbar, tipografía, estados reales, accesibilidad y revisión responsive. Se adapta la entrega de prototipo HTML del template a Next.js para conectar datos reales. No se necesita ejecutar Open Design como dependencia del producto. No se copió código del workspace ni se atribuye a Open Design la generación por un modelo que no se ejecutó.

Open Design se publica bajo Apache-2.0; frontend-design declara adaptación del skill de Anthropic. Esta documentación conserva atribución y enlaces originales.
