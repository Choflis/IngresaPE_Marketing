# Ingresa PE Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Entregar un estudio privado ejecutable para producir videos e imágenes de Ingresa PE por áreas y por lotes.

**Architecture:** Next.js sirve el panel/API. PostgreSQL almacena catálogo normalizado y pg-boss almacena tareas. Worker separado genera medios, guarda solicitudes remotas y compone con Remotion/Sharp.

**Tech Stack:** Next.js, TypeScript, PostgreSQL, pg-boss, Remotion, Sharp, Runway SDK, Docker.

**Spec:** docs/superpowers/specs/2026-10-28-studio-design.md

## Global Constraints

- Privado, un propietario, español. Credenciales solo servidor.
- PostgreSQL normalizado, FKs y versiones inmutables.
- No reintentar automáticamente una creación pagada con resultado ambiguo.
- Modo demo explícito y ningún resultado Runway inventado.

## Review Focus

- Lotes simultáneos: evitar duplicados y superar presupuesto mediante transacciones.
- Reinicio después de enviar al proveedor: recuperar task ID, no volver a cobrar.
- Orígenes externos y sesiones vencidas: denegar mutación y medios.
- Preguntas inválidas o repetidas: rollback completo y validación consistente.
- Archivo remoto expirado/proveedor caído: reintento de descarga o polling, nunca nueva generación.
